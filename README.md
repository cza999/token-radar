Token Radar ranks the 40 watchlist DeFi protocols (TVL of at least $50M, no token on record) by implied token value, derived from a sealed DefiLlama snapshot, and ships a static dashboard with a factor breakdown and a farm plan for every row.

## Run it

```sh
node main.ts
```

Reads `/input/snapshot.json`, writes `/output/board.json` and `/output/data.js`, and copies `dashboard/` and `screenshots/` into `/output`.
